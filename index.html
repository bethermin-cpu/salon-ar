Commandes dans le Quest
  • Gâchette : poser le meuble choisi sur le sol visé
  • Grip maintenu : attraper le meuble le plus proche et le déplacer
  • Joystick gauche/droite : tourner le meuble sélectionné
  • A / X : meuble suivant du catalogue
  • B / Y : supprimer le meuble sélectionné
  • Clic joystick : déplier / replier le canapé convertible (encombrement du lit pour les autres meubles)
  • Viser le pied du mur : le dos du canapé s'y plaque. Viser le mur lui-même : le meuble s'aligne dessus

Sur téléphone : touchez l'écran pour poser, boutons en bas pour le reste. En AR, les meubles posés ne sont pas conservés après la sortie.

Glisser : tourner la vue · clic sur un meuble : le choisir · clic au sol : l'y déplacer
